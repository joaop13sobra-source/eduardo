# Mapa do acervo Edutran

Inventário de 04/11/2026: seis cursos, 44 módulos. Os caminhos abaixo são relativos à raiz Eduardo. Não equivalem a matriz curricular oficial validada. Para inventário atualizado, executar `scripts/indexar_acervo.py`.

## Resolver o pedido

- Cargas indivisíveis, CETCI, AET, carga excedente → curso 1.
- Emergência, ambulância, viatura → curso 2.
- Escolar, crianças, responsáveis, transporte de alunos → curso 3.
- Reciclagem, condutor infrator → curso 4.
- MOPP, CETPP, produto perigoso → curso 5.
- Coletivo, ônibus, passageiros → curso 6.
- Direção defensiva, legislação, primeiros socorros e meio ambiente aparecem em vários cursos: escolher contexto, não pegar a primeira ocorrência.
- Formação de instrutores aparece na divulgação pública, mas não há trilha completa específica no acervo inventariado. Para uma aula de instrutores, usar o módulo indicado como conteúdo e adaptar o método; não inventar curso completo ou requisitos de credenciamento.

## Contexto transversal

- `reports/Acervo cursos especializados de trânsito.md`: síntese e divergências a verificar.
- `research_notes/Acervo cursos especializados de trânsito/`: oito notas temáticas para localizar fontes e pendências.
- `Índice.jpeg`: foto do índice de manual de terceiros; útil para organização histórica, não identidade da marca nem norma vigente.
